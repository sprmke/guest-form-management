## Smart AI Data Importer (bookings)

Property-scoped spreadsheet import wizard — upload host booking history into `guest_submissions` without triggering live booking side effects.

| Concern            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tables**         | `import_batches` (batch lifecycle + column mapping), `import_batch_rows` (staged raw/mapped rows). `guest_submissions.imported_from_batch_id` → `import_batches.id`.                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Storage**        | Private bucket **`import-uploads`** — CSV / Excel (`.csv`, `.xlsx`, `.xls`), 15 MB cap; path `{orgId}/{batchId}/{filename}`. First worksheet only for Excel.                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Booking status** | Committed rows get **`status = 'IMPORTED'`** (direct insert from `import-commit`, not `workflowOrchestrator`). Manual overrides only: `IMPORTED → PENDING_REVIEW` \| `CANCELLED`. Excluded from action-required stage cards, SD-refund cron, and guest calendar availability.                                                                                                                                                                                                                                                                                          |
| **Permissions**    | **`org:import:manage`** (org owner + admin by default) and property **`import:manage`** (explicit per-member grant only — not in built-in role defaults). All `import-*` endpoints use `resolveImportAccess` → `verifyPropertyAccess(..., 'import:manage')`.                                                                                                                                                                                                                                                                                                           |
| **Edge functions** | `import-parse-file`, `import-ai-map-columns`, `import-save-mapping`, `import-preview`, `import-update-row`, `import-commit`, `import-revert`, `import-cancel`, `import-list-batches` — see [`docs/architecture/edge-functions.md`](architecture/edge-functions.md).                                                                                                                                                                                                                                                                                                    |
| **UI**             | **Import** button on property bookings list → four-step `ImportWizardModal` (Upload → Match → Preview → Import). Match keeps automatic and manual review together in clickable **Matched** / **Need input** summary cards, auto-selecting Need input when action is required. Preview has status filters, an error queue, and an in-app fix sheet (`fieldValues` on `import-update-row`); skipped rows reopen the same sheet with **Restore** / **Fix**, walking the skipped queue instead of the error queue. Validation errors include `value` for the failing cell. |
| **Route guides**   | [`docs/guides/routes/org/property/bookings.md`](guides/routes/org/property/bookings.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

## Platform AI metering (production cost control)

Centralized Gemini usage for receipts, inbox drafts, marketing AI, import column mapping, voice transcript polish, and voice receptionist sessions. Per-property overrides and hard-enforced quotas are live; voice is now gated by the same platform-wide kill switch and allowlist.

| Concern                 | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tables**              | `ai_platform_global_settings` (kill switch + `enforce_quotas` + `allowed_features` + default quotas + `credit_unit_usd` + `voice_receptionist_cost_per_minute_usd` + `default_daily_credit_limit`/`default_monthly_credit_limit`), `ai_platform_org_settings` (per-org enable + daily/monthly **call** + daily USD cost limits + `daily_credit_limit`/`monthly_credit_limit` overrides), `ai_platform_property_settings` (per-property overrides, same credit-limit columns + `feature_configs` JSONB for per-feature knobs e.g. `voice_receptionist`), `ai_platform_property_usage_daily` (per-property counters + `credits_consumed`), `ai_platform_usage_daily` (org aggregates + `credits_consumed`), `ai_platform_usage_events` (audit log — `actor_user_id`/`actor_type`/`cost_basis`/`duration_seconds`/`credits_consumed`), `ai_platform_response_cache` (deterministic prompt cache), `ai_platform_org_credit_wallet` + `ai_platform_org_credit_ledger` (purchased top-up credits — **live enforcement**: drawn down atomically once an org's or property's daily/monthly credit allowance is exceeded; see [`docs/workflow/in-progress/ai-usage-metering-credits-foundation.md`](workflow/in-progress/ai-usage-metering-credits-foundation.md)). |
| **Shared edge modules** | `_shared/aiModelRouter.ts` (feature → Flash / Flash-Lite / Live), `_shared/aiGeminiKeys.ts` (key rotation), `_shared/aiQuotaCache.ts` (SHA-256 prompt cache), `_shared/aiUsageService.ts` (`isFeatureEnabled`, `assertOrgAndPropertyAiQuota`, `recordAiUsage`, property settings), `_shared/aiCreditLedger.ts` (`estimateCreditsFromCostUsd`, `adjustOrgCreditWallet`, `getRecentCreditLedgerEntries`), `_shared/geminiToolCallClient.ts` (tool calls + structured output), `_shared/dashboardAssistantContext.ts`, `_shared/dashboardAssistantRiskClassifier.ts`, `_shared/dashboardAssistantSafetyGuard.ts`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **Model tiering**       | Vision / structured JSON / dashboard assistant → **Gemini 2.5 Flash**; inbox / captions / import column map / voice polish / integration verify → **Flash-Lite**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Quota behavior**      | Inbox + marketing → HTTP **429** + `upgradeHook: true`; receipt + import → non-blocking degrade (`aiModelError` or unmatched columns). Voice polish skips polish on quota (raw transcript). Per-property limits override org limits. Credit limits (daily/monthly) sit alongside call/cost limits — once exceeded, calls draw from the org's credit wallet if it has a positive balance, else 429.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Defaults**            | 200 calls/day, 5000 calls/month, $10/day per org; platform-wide `enabled` defaults to `false` so super-admin must explicitly turn AI on. Credit limits default to 100,000/day and 1,000,000/mo — deliberately generous working numbers (not real pricing) so this gate is inert under current usage; see the linked plan doc's Open Decisions before tightening.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Edge functions**      | `ai-platform-global-settings` (super-admin), `ai-platform-settings`, `ai-platform-usage`, `ai-platform-property-settings`, `ai-platform-credit-wallet` (super-admin, org wallet balance/ledger + manual adjustment) — see [`docs/architecture/edge-functions.md`](architecture/edge-functions.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **UI**                  | Org **Settings → AI usage** (`OrgAiPlatformSection` — credits progress + wallet balance); property **Settings → AI Overrides** (`PropertyAiPlatformSection`); super-admin kill switch + credit wallet on `/admin`. Plan-tier **Upgrade** opens **`SubscriptionUpgradeModal`** (→ property Plans); **Buy credits** stub unchanged.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Ops**                 | Paid **`GEMINI_API_KEY`** on one billing project for hosted envs; multi-key rotation local-only — [`docs/archive/operations/ai-platform-billing.md`](archive/operations/ai-platform-billing.md), [`docs/architecture/validation-and-env.md`](architecture/validation-and-env.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## AI Dashboard Assistant (chat + actions in the admin dashboard)

Chat assistant embedded in the admin dashboard — Q&A over live operational data plus tiered-confirmation write actions across bookings, finance, maintenance, org/team, property settings, parking, pricing, guest inbox, and marketing. Fully independent of Platform AI metering above: own tables, own two-layer kill switch, own soft-cap quota — no shared infrastructure, though it still reuses `_shared/aiUsageService.ts`'s underlying `dashboard_assistant` feature gate via `geminiToolCallClient.ts`. **v1 shipped; v2 full-coverage expansion shipped (all 8 phases)** — **full tool-by-tool reference (what's allowed, what's not, why): [`docs/architecture/ai-dashboard-assistant.md`](architecture/ai-dashboard-assistant.md)**. v1 plan: [`docs/workflow/done/ai-dashboard-assistant.md`](workflow/done/ai-dashboard-assistant.md); v1 build log: [`docs/workflow/done/ai-platform-hardening-handoff.md`](workflow/done/ai-platform-hardening-handoff.md); v2 plan + phase log: [`docs/workflow/done/ai-dashboard-assistant-v2-full-coverage.md`](workflow/done/ai-dashboard-assistant-v2-full-coverage.md); plain-language feature list: [`docs/workflow/done/ai-dashboard-assistant-features.md`](workflow/done/ai-dashboard-assistant-features.md); manual test guide: [`docs/guides/testing/ai-dashboard-assistant-manual.md`](guides/testing/ai-dashboard-assistant-manual.md).

| Concern            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tables**         | `ai_dashboard_assistant_global_settings` (singleton kill switch), `ai_dashboard_assistant_org_settings` (opt-in + per-property disable list + message/write-action quotas), `ai_dashboard_assistant_conversations`/`_messages` (private per user; `_messages.attachments` JSONB metadata only), `ai_dashboard_assistant_pending_actions` (Tier-2 proposals, 15-min TTL), `ai_dashboard_assistant_usage_daily`, `ai_dashboard_assistant_action_audit`, `ai_dashboard_assistant_knowledge_base` (synced from route guides). Storage bucket **`ai-assistant-attachments`** (private, JPEG/PNG/WebP/PDF, 4 MB).                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Risk tiers**     | Tier 0 (read, always allowed) / Tier 1 (auto-executed, "done automatically" notice) / Tier 2 (explicit confirm-click) — computed deterministically by `_shared/dashboardAssistantRiskClassifier.ts#classifyActionRisk()` from `statusMachine.ts`'s real transition graph, never asserted by the model. Re-derived from current DB state immediately before every execution by `_shared/dashboardAssistantSafetyGuard.ts#assertActionSafeToExecute()`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Tool catalog**   | `_shared/dashboardAssistantTools.ts` — 64 tools (35 read, 29 write) spanning bookings/finance/maintenance/org/team/property/parking/pricing/inbox/marketing — all 8 planned v2 phases shipped. `propose_send_inbox_reply` and `propose_publish_to_meta` are the two external-send tools (real message/post, no undo). Marketing tools are the one exception to the property-team RBAC model — gated at the global admin allowlist instead, matching the real Marketing Studio's current access boundary. **Full tool-by-tool table with tiers, RBAC, and what's explicitly excluded: [`docs/architecture/ai-dashboard-assistant.md`](architecture/ai-dashboard-assistant.md).**                                                                                                                                                                                                                                                                                                                                               |
| **Edge functions** | `dashboard-assistant-chat` (main turn, bounded tool-calling loop), `dashboard-assistant-confirm` (Tier-2 execution), `dashboard-assistant-conversations`, `dashboard-assistant-settings`, `dashboard-assistant-global-settings`, `dashboard-assistant-expire-pending-actions` (cron), `get-booking`, `get-booking-ai-assistant-audit` — see [`docs/architecture/edge-functions.md`](architecture/edge-functions.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **UI**             | Desktop: floating launcher (`lg+`) stacked under the notification FAB; mobile: **Assistant** bottom tab. Slide-over panel (`ui/src/features/dashboard/ai-assistant/`) mounted in `AdminLayout.tsx`; typed `ChatBlock` renderer (`text`/`booking_card`/`stat_list`/`data_table`/`link_list`/`file_list`/`action_confirmation`) — never free-form AI-generated HTML/markdown. Empty structured cards are not rendered; status codes in text are shown as human labels. Booking files (approved GAF, receipts, IDs) render as preview cards from grounded storage URLs. Empty chat centers a **Questions / Actions** mode switch (filled teal pill) and 5 randomized prompt cards from a 20+20 pool in `assistantSuggestions.ts`. Sending shows an incoming-message thinking bubble (sparkles + dots). Composer text is full-width above attach / pin / send and grows with typed lines (max 10, then scroll). Org settings section + super-admin kill-switch card. Booking-detail "Actions taken by AI assistant" audit viewer. |
| **Not yet built**  | No parking-scoped tools in v1.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

## Help & Support (org + property + parking)

Guides + AI Chat entry point + support tickets + FAQs for hosts, at org/property/parking scope. **All 6 phases shipped** (Foundation, Documentation + AI Chat, FAQs, Ticket support, Super-admin, Nav + routing); plan + phase-by-phase progress log: [`workflow/in-progress/help-support-center.md`](workflow/in-progress/help-support-center.md). Reuses `ai_dashboard_assistant_knowledge_base` (see above) as the shared content source for Guides instead of a parallel table. Host UI is a Help & Support page with persistent clickable `StatCard`s (FAQs, Guides, Tickets, Ask AI). Nested Guides/Tickets URLs stay for deep links, but the admin page-enter animation keys off `/help-support` so switching modules only replaces the content below the cards.

| Concern            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

Storage bucket **`support-ticket-attachments`** (private, images + `video/mp4`/`video/quicktime`, 20MB).                                                                                                                                                                                                                                                                                                                                                                       |
