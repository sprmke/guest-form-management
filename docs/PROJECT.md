## Smart AI Data Importer (bookings)

Property-scoped spreadsheet import wizard — upload host booking history into `guest_submissions` without triggering live booking side effects.

| Concern            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tables**         | `import_batches` (batch lifecycle + column mapping), `import_batch_rows` (staged raw/mapped rows). `guest_submissions.imported_from_batch_id` → `import_batches.id`.                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Storage**        | Private bucket **`import-uploads`** — CSV / Excel (`.csv`, `.xlsx`, `.xls`), 15 MB cap; path `{orgId}/{batchId}/{filename}`. First worksheet only for Excel.                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Booking status** | Committed rows get **`status = 'IMPORTED'`** (direct insert from `import-commit`, not `workflowOrchestrator`). Manual overrides only: `IMPORTED → PENDING_REVIEW` \| `CANCELLED`. Excluded from action-required stage cards, SD-refund cron, and guest calendar availability.                                                                                                                                                                                                                                                                                          |
| **Permissions**    | **`org:import:manage`** (org owner + admin by default) and property **`import:manage`** (explicit per-member grant only — not in built-in role defaults). All `import-*` endpoints use `resolveImportAccess` → `verifyPropertyAccess(..., 'import:manage')`.                                                                                                                                                                                                                                                                                                           |
| **Edge functions** | `import-parse-file`, `import-ai-map-columns`, `import-save-mapping`, `import-preview`, `import-update-row`, `import-commit`, `import-revert`, `import-cancel`, `import-list-batches` — see [`docs/architecture/edge-functions.md`](architecture/edge-functions.md).                                                                                                                                                                                                                                                                                                    |
| **UI**             | **Import** button on property bookings list → four-step `ImportWizardModal` (Upload → Match → Preview → Import). Match keeps automatic and manual review together in clickable **Matched** / **Need input** summary cards, auto-selecting Need input when action is required. Preview has status filters, an error queue, and an in-app fix sheet (`fieldValues` on `import-update-row`); skipped rows reopen the same sheet with **Restore** / **Fix**, walking the skipped queue instead of the error queue. Validation errors include `value` for the failing cell. |
| **Route guides**   | [`docs/guides/routes/org/property/bookings.md`](guides/routes/org/property/bookings.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

## Platform AI metering (production cost control)

Centralized Gemini usage for receipts, inbox drafts, marketing AI, import column mapping, voice transcript polish, and voice receptionist sessions. Per-property overrides and hard-enforced quotas are live; voice is now gated by the same platform-wide kill switch and allowlist.

| Concern                 | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tables**              | `ai_platform_global_settings` (kill switch + `enforce_quotas` + `allowed_features` + default quotas), `ai_platform_org_settings` (per-org enable + daily/monthly **call** + daily USD cost limits), `ai_platform_property_settings` (per-property overrides), `ai_platform_property_usage_daily` (per-property counters), `ai_platform_usage_daily` (org aggregates), `ai_platform_usage_events` (audit log), `ai_platform_response_cache` (deterministic prompt cache).                  |
| **Shared edge modules** | `_shared/aiModelRouter.ts` (feature → Flash / Flash-Lite / Live), `_shared/aiGeminiKeys.ts` (key rotation), `_shared/aiQuotaCache.ts` (SHA-256 prompt cache), `_shared/aiUsageService.ts` (`isFeatureEnabled`, `assertOrgAndPropertyAiQuota`, `recordAiUsage`, property settings), `_shared/geminiToolCallClient.ts` (tool calls + structured output), `_shared/dashboardAssistantContext.ts`, `_shared/dashboardAssistantRiskClassifier.ts`, `_shared/dashboardAssistantSafetyGuard.ts`. |
| **Model tiering**       | Vision / structured JSON / dashboard assistant → **Gemini 2.5 Flash**; inbox / captions / import column map / voice polish / integration verify → **Flash-Lite**.                                                                                                                                                                                                                                                                                                                         |
| **Quota behavior**      | Inbox + marketing → HTTP **429** + `upgradeHook: true`; receipt + import → non-blocking degrade (`aiModelError` or unmatched columns). Voice polish skips polish on quota (raw transcript). Per-property limits override org limits.                                                                                                                                                                                                                                                      |
| **Defaults**            | 200 calls/day, 5000 calls/month, $10/day per org; platform-wide `enabled` defaults to `false` so super-admin must explicitly turn AI on.                                                                                                                                                                                                                                                                                                                                                  |
| **Edge functions**      | `ai-platform-global-settings` (super-admin), `ai-platform-settings`, `ai-platform-usage`, `ai-platform-property-settings`, `dashboard-assistant` — see [`docs/architecture/edge-functions.md`](architecture/edge-functions.md).                                                                                                                                                                                                                                                           |
| **UI**                  | Org **Settings → AI usage** (`OrgAiPlatformSection`); property **Settings → AI Overrides** (`PropertyAiPlatformSection`); super-admin kill switch + feature toggles on `/admin`. Upgrade CTA is a stub toast until Stripe billing ships.                                                                                                                                                                                                                                                  |
| **Ops**                 | Paid **`GEMINI_API_KEY`** on one billing project for hosted envs; multi-key rotation local-only — [`docs/archive/operations/ai-platform-billing.md`](archive/operations/ai-platform-billing.md), [`docs/architecture/validation-and-env.md`](architecture/validation-and-env.md).                                                                                                                                                                                                         |

## AI Dashboard Assistant (chat + actions in the admin dashboard)

Chat assistant embedded in the admin dashboard — Q&A over live operational data plus tiered-confirmation write actions (booking transitions, cancellation, receipt re-validation). Fully independent of Platform AI metering above: own tables, own two-layer kill switch, own soft-cap quota — no shared infrastructure, though it still reuses `_shared/aiUsageService.ts`'s underlying `dashboard_assistant` feature gate via `geminiToolCallClient.ts`. **v1 shipped** — plan: [`docs/workflow/done/ai-dashboard-assistant.md`](workflow/done/ai-dashboard-assistant.md); build log: [`docs/workflow/done/ai-platform-hardening-handoff.md`](workflow/done/ai-platform-hardening-handoff.md); plain-language feature list: [`docs/workflow/done/ai-dashboard-assistant-features.md`](workflow/done/ai-dashboard-assistant-features.md); manual test guide: [`docs/guides/testing/ai-dashboard-assistant-manual.md`](guides/testing/ai-dashboard-assistant-manual.md).

| Concern            | Detail                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Tables**         | `ai_dashboard_assistant_global_settings` (singleton kill switch), `ai_dashboard_assistant_org_settings` (opt-in + per-property disable list + message/write-action quotas), `ai_dashboard_assistant_conversations`/`_messages` (private per user), `ai_dashboard_assistant_pending_actions` (Tier-2 proposals, 15-min TTL), `ai_dashboard_assistant_usage_daily`, `ai_dashboard_assistant_action_audit`, `ai_dashboard_assistant_knowledge_base` (synced from route guides).   |
| **Risk tiers**     | Tier 0 (read, always allowed) / Tier 1 (auto-executed, "done automatically" notice) / Tier 2 (explicit confirm-click) — computed deterministically by `_shared/dashboardAssistantRiskClassifier.ts#classifyActionRisk()` from `statusMachine.ts`'s real transition graph, never asserted by the model. Re-derived from current DB state immediately before every execution by `_shared/dashboardAssistantSafetyGuard.ts#assertActionSafeToExecute()`.                          |
| **Tool catalog**   | `_shared/dashboardAssistantTools.ts` — read tools (`search_knowledge_base`, `explain_booking_status`, `get_booking`, `list_bookings`, `get_available_transitions`, `get_dashboard_stats`, `get_finance_summary`, `list_finance_bookings`, `get_maintenance_summary`, `list_maintenance_items`) and write tools (`run_receipt_validation`, `propose_transition_booking`, `propose_cancel_booking`). Every tool independently re-checks RBAC against the original request's JWT. |
| **Edge functions** | `dashboard-assistant-chat` (main turn, bounded tool-calling loop), `dashboard-assistant-confirm` (Tier-2 execution), `dashboard-assistant-conversations`, `dashboard-assistant-settings`, `dashboard-assistant-global-settings`, `dashboard-assistant-expire-pending-actions` (cron), `get-booking`, `get-booking-ai-assistant-audit` — see [`docs/architecture/edge-functions.md`](architecture/edge-functions.md).                                                           |
| **UI**             | Launcher button + slide-over panel (`ui/src/features/dashboard/ai-assistant/`) mounted in `AdminLayout.tsx`; typed `ChatBlock` renderer (`text`/`booking_card`/`stat_list`/`data_table`/`link_list`/`action_confirmation`) — never free-form AI-generated HTML/markdown. Org settings section + super-admin kill-switch card. Booking-detail "Actions taken by AI assistant" audit viewer.                                                                                     |
| **Not yet built**  | The tool-calling chat rewrite of the older `dashboard-assistant` plain-text stub is separate — both endpoints exist today. Frontend has no conversation-history browsing UI beyond "New conversation" (backend `dashboard-assistant-conversations` GET supports it). No parking-scoped tools in v1.                                                                                                                                                                            |
