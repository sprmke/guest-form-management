# superpowers-execute

Execute an existing Superpowers plan.

1. Read the plan path the user gives, or the latest `docs/superpowers/plans/*.md` if they did not specify one.
2. Follow **`superpowers:subagent-driven-development`** (preferred) or **`superpowers:executing-plans`**.

This command opts in to Superpowers for the current chat. Available as **/superpowers-execute**.
